MSI Sales Report — Excel Dashboard Project
Built an interactive Excel sales dashboard analyzing employee, department, and regional sales performance (Sales, Purchase, Profit, Units) across products and
months, using structured Excel Tables, PivotTables, and formula-based aggregations (SUM, AVERAGE). Designed 11 PivotCharts (bar, line, and pie visualizations)
covering sales by region, monthly sales trends, salesperson performance, and units sold, with slicers and a date timeline for dynamic filtering.
Tools use: Excel Tables, PivotTables, PivotCharts, Formulas (SUM, AVERAGE), Slicers, Timeline Filters, Interactive Dashboard Design
